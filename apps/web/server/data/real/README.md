# Real reference datasets (`server/data/real/`)

Compact JSON files committed to the repo and loaded **synchronously** by the
deterministic demo seed (`server/data/store.ts`, `server/data/seed-assets.ts`)
through the typed loaders in `index.ts`. Total size ≈ 0.25 MB. Every file is
regenerated by a script in `scripts/data/` (Python 3.10+, `requests`, `numpy`,
`pandas`, `matplotlib`, `Pillow`; no API keys). Raw API responses are cached in
`scripts/data/.cache/` (git-ignored), so re-runs are cheap.

Retrieval date for the committed files: **2026-09-29**.
Author: Nitya Prakash Pandey.

| File | Built by | What it holds |
|---|---|---|
| `flood-events.json` | `scripts/data/build_hazard_events.py` | Real flood episodes per district, 2019-01-01 → last available day |
| `salinity-seasons.json` | same | Dry-season salt-intrusion severity per district-year |
| `dry-spells.json` | same | In-season rainfall-deficit (drought) episodes |
| `cyclones.json` | same | Tropical cyclones whose wind field reached each district |
| `commodity-prices.json` | `scripts/data/build_commodity_prices.py` | Monthly USD prices 2021-01 → latest print |
| `district-boundaries.json` | `scripts/data/build_district_boundaries.py` | Real admin boundary ring per district (60–150 vertices) |
| `land-points.json` | `scripts/data/build_land_points.py` | 24 land-validated farm sites × (home + 5 plots) per district |
| `facilities.json` | same | Real coordinates of the 20 supply-chain facilities |
| `fx-snapshot.json` | `scripts/data/build_fx_snapshot.py` | USD FX table (fallback for `server/live/fx.ts`) |
| `agri-reference.json` | curated by hand | Farm sizes, household statistics, loan rates, premiums, costs of cultivation |

Regenerate everything (from the repo root):

```bash
python scripts/data/build_hazard_events.py      # ~2 min first run (GDACS geometries), seconds when cached
python scripts/data/build_commodity_prices.py   # downloads the Pink Sheet + WFP India CSV (~25 MB)
python scripts/data/build_district_boundaries.py  # run before build_land_points.py (points are sampled inside these rings)
python scripts/data/build_land_points.py        # ~30-60 min first run (≈1,000 JRC + DEM tiles), fast when cached
python scripts/data/build_fx_snapshot.py
cd apps/web && npx vitest run tests/data-*.test.ts
```

## 1. Flood events — `flood-events.json`

* **Sources**: `apps/ml-api/data/flood_dataset.csv.gz` (the ML service's committed daily
  panel: ERA5 rainfall from the Open-Meteo Historical Weather API and Copernicus
  **GloFAS v4** river discharge from the Open-Meteo Flood API, 2019-01-01 → 2025-12-31),
  extended to the present with the same two APIs (`archive-api.open-meteo.com`,
  `flood-api.open-meteo.com`) at the same GloFAS cells (`apps/ml-api/data/sites.json`).
* **Licence**: Open-Meteo data CC BY 4.0; ERA5 © ECMWF/Copernicus C3S; GloFAS © Copernicus EMS.
* **Transformation**: identical to the ML flood labels (`apps/ml-api/core/features.py`):
  a day is a flood day when discharge > P95 of the 2019–2022 training period **or** the
  3-day rainfall > P99 (≥ 20 mm). Flood days less than 7 days apart are merged into one
  episode. Per episode: start, end, peak date, peak discharge, max 3-day rain, total rain,
  driver (riverine / pluvial / both) and the physically-derived depth proxy
  `1.5·max(0,(Q/P95)^0.6 − 1) + max(0, R3 − 90)/1000·4/(1 + elev/8)` m.
* **Used for**: `districts[].historicalFloods` (worst episode per year) and the flood
  alerts in the 200-alert archive (issued 1–3 days before the real onset).

### Loss model (historical floods & archived alerts) — `index.ts#floodLoss`

```
floodedHa   = vulnerableAreaHa × clamp(0.005 + 0.35·(1 − e^(−depth/0.7))·(0.4 + 0.6·min(1, days/14)), 0.002, 0.5)
damage      = clamp(0.2 + 0.6·(1 − e^(−depth/0.8)) + 0.012·days, 0.1, 0.95)
cropValue   = paddy yield (FAOSTAT 2023, t/ha) × farm-gate paddy price (USD/t)      [agri-reference.json]
lossUsd     = floodedHa × cropValue × damage × seasonFactor (1 in the wet-season crop window, 0.5 otherwise)
farms       = floodedHa / country mean farm size
```
Depth → damage follows the shape of rice submergence damage curves (damage rises steeply
past ~0.5 m and after 7–10 days of submergence). It is a transparent proxy, not a
calibrated damage model.

## 2. Salinity seasons — `salinity-seasons.json`

* **Sources**: GloFAS v4 daily discharge (Open-Meteo Flood API) 2012 → present at four
  main-stem cells — Mekong at **Kratie** (12.425, 105.975; upstream of tidal influence) for
  the Vietnamese districts, Ganges at **Hardinge Bridge** for coastal Bangladesh, Mahanadi at
  **Naraj** for Odisha, Pampanga at **Arayat** for Pampanga/Bulacan; ERA5 rainfall for the
  Java north coast (whose canals salinise with the dry-season rainfall deficit).
* **Transformation**: per dry season (VN/BD/PH Jan–May, Odisha Feb–Jun, Java Jun–Nov) the
  minimum 30-day mean discharge `Qmin` → intrusion index `clamp((Qmin/median Qmin)^−0.6, 0.5, 2.5)`
  (salt-intrusion length ∝ Q^−0.6, Savenije 2005). Onset = first day the 30-day flow drops
  below the long-run dry-season median; peak = day of minimum flow. Peak root-zone ECe =
  the ML dataset's calibrated typical dry-season P95 `0.6 + 15·s²` (s = district salinity
  exposure) × `min(1.45, index^0.5)`.
* **What the real record shows**: the Mekong at Kratie had its lowest dry-season flows of the
  period in **2020, 2021 and 2024** (index 2.0–2.3) — matching the documented severe
  intrusion years 2020 and 2024 in the Mekong Delta; the Ganges shows no comparable
  2020/2024 deficit in GloFAS, so Bangladesh severities stay near normal. Absolute ECe
  levels are a calibrated prior (the same caveat as the ML salinity dataset).
* **Used for**: salinity alerts (issued 5–10 days before the real onset; severity by peak
  ECe: ≥ 12 emergency, ≥ 6 warning, ≥ 3 watch; loss via the Maas–Hoffman rice response).

## 3. Dry spells — `dry-spells.json`

ERA5 daily rainfall (same panel). 30-day rainfall below 45 % of the 2019–2025 day-of-year
median during the main crop season, where that normal is ≥ 150 mm/30 d, for ≥ 10 days.
Few such spells occurred in these monsoon deltas (18 in 2019–2026) — that is the real record.

## 4. Tropical cyclones — `cyclones.json`

* **Source**: GDACS (Global Disaster Alert and Coordination System, EC JRC / UN OCHA) event
  API `gdacsapi/api/events/geteventlist/SEARCH?eventlist=TC&country=…` and per-event
  geometry `polygons/getgeometry` (track advisories + 60/90/120 km/h wind buffers).
* **Transformation**: a district is hit when its centroid lies in a wind buffer (red ≥ 120,
  orange ≥ 90, green ≥ 60 km/h) or the track passes within 150 km; the date is the closest
  advisory point. Examples: Fani 2019, Bulbul 2019, Amphan 2020, Vamco 2020, Yaas 2021,
  Sitrang 2022, Remal 2024, Dana 2024, Trami 2024, Fung-wong 2025.
* **Licence**: GDACS content is free to reuse with attribution.

## 5. Commodity prices — `commodity-prices.json`

* **World Bank Commodity Price Data (The Pink Sheet)**, monthly, nominal USD, CC BY 4.0.
  URL discovered from <https://www.worldbank.org/en/research/commodity-markets>
  (committed file: `…/74e8be41ceb20fa0da750cda2f6b9e4e-0050012026/related/CMO-Historical-Data-Monthly.xlsx`,
  "Updated on September 02, 2026", data through 2026-08). Parsed with the dependency-free
  `scripts/data/xlsx_min.py`. Series: rice Thai 5 %, rice Viet Namese 5 %, wheat US HRW,
  maize, sugar (world), coconut oil, palm oil, urea, DAP.
* **WFP food prices for India** via HDX (`wfp-food-prices-for-india`, CC BY-IGO): national
  mean retail onion and tomato+potato prices in USD (WFP's own `usdprice`).
* **Jute** is not in the Pink Sheet. Proxy: Government of India raw-jute MSP (CACP; INR 4,225
  → 5,650 per quintal for the 2020-21 → 2025-26 seasons) converted with the World Bank annual
  official exchange rate `PA.NUS.FCRF` (current spot for years not yet published).
* **App commodity mapping** (`commodities[<name>]`): rice = Thai 5 %; wheat = US HRW;
  maize = US maize; sugarcane = world raw sugar × 0.105 (recoverable sucrose per tonne of
  cane); coconut = coconut oil × 0.63 (copra equivalent); jute = MSP proxy; onion = WFP
  retail × 0.36 and vegetables = WFP retail × 0.35 (farmer's share of the consumer rupee,
  RBI Working Paper 2024).
* **Used for**: `commodities[].priceHistory` = the monthly series (anchored mid-month)
  linearly interpolated to 26 weekly points ending today, held flat after the latest print;
  `basePriceUsd` = trailing 12-month mean. `index.ts#commodityPriceMeta()` exposes the
  method/source for SourceTags.

## 6. Land-validated points — `land-points.json`, `facilities.json`

* **Admin boundaries**: every point lies inside the district ring of `district-boundaries.json`
  (section 6a).
* **Elevation**: Tilezen/Mapzen *Terrarium* elevation tiles (AWS Open Data Registry,
  `s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png`, SRTM-based over the study
  area; zoom 12 ≈ 38 m; `h = R·256 + G + B/256 − 32768`): accepted when 0 m < elevation < 120 m
  (the sea is ≤ 0 — bathymetry is negative; the upper bound keeps plots on the lowland farming
  plain). The Open-Meteo Elevation API (Copernicus GLO-90, 100 points/request) was tried first,
  but validating ~10k candidates exhausts Open-Meteo's free hourly quota — which the ML
  service's live calls share — so the builder uses the tile source on the same grid as the
  water mask. Terrain data © Mapzen/Tilezen and its sources (SRTM: NASA/USGS, public domain).
* **Water mask**: JRC Global Surface Water occurrence 1984–2021 (tiles2021, zoom 12,
  ≈ 38 m pixels; alpha channel = occurrence): rejected when the pixel is ≥ 15 % water or any
  pixel of the 3×3 neighbourhood is ≥ 50 % — removes rivers, canals, ponds, shrimp gher and sea.
  © EC JRC / Google, Pekel et al. 2016, *Nature* 540.
* **Sampling**: Halton sequence inside the polygon (and within 0.4° of the centroid); each
  accepted homestead gets 5 plots 250–900 m away that also pass every check. Stored with
  their DEM elevation.
* **Facilities**: the 20 supply-chain nodes placed at their real approximate locations (e.g.
  Chattogram port 22.311, 91.800; Mongla 22.488, 89.596; Cái Mép 10.537, 107.030; Paradip
  20.264, 86.672; Tanjung Emas −6.948, 110.419; Manila North Harbor 14.609, 120.960;
  Pasar Induk Beras Cipinang −6.214, 106.881), each cross-checked with an OpenStreetMap
  Nominatim search (`offsetKm` = distance to the OSM result; ODbL).
  Waterfront pins (ports, riverside mills) that fell on water pixels are snapped to the
  nearest pixel passing the land checks (`snappedM`, 30–430 m).
* **Used for**: every farmer home, field, workspace asset (insured plots, loans,
  communities, co-op farms), depot and supply node coordinate in the seed.

## 6a. District boundaries — `district-boundaries.json`

* **Source**: geoBoundaries gbOpen, <https://www.geoboundaries.org> (Runfola et al. 2020,
  *PLoS ONE* 15(4): e0231866). Licences differ per country and are recorded per district:
  BGD ADM2, PHL ADM2 and IDN ADM2 — **CC BY 3.0 IGO**; VNM ADM1 — **public domain** (2008
  provinces, i.e. before the July-2025 provincial mergers; full-resolution file because the
  simplified one has only ~70 vertices per province); IND ADM2 — **ODbL 1.0**.
* **Unit selection**: the unit containing the app's district centroid; Pekalongan = regency +
  the enclosed city (the app's population is the regency's); Semarang = Kota Semarang.
* **Transformation**: single-part units → the outer ring. Multi-part units (the Bangladesh
  coastal districts are split into chars and islands by tidal channels; Pekalongan's merge) →
  rasterised at ≈ 250 m, a 1.5 km morphological closing joins islands across channels, holes
  filled, largest connected footprint traced back to a ring. This keeps `geometry` a single
  GeoJSON `Polygon` (every map/area consumer reads `coordinates[0]`). Then Douglas–Peucker
  with a bisected tolerance to 60–150 vertices, 5-decimal coordinates, counter-clockwise
  exterior (RFC 7946). Resulting areas are within ~15 % of official figures (e.g. Barisal
  2,431 vs 2,785 km², Nueva Ecija 5,528 vs 5,751 km², Kota Semarang 391 vs 374 km²).
* **Used for**: `districts[].geometry` (maps, district areas / farmer density, polygon
  selection) and as the sampling domain of `land-points.json`.

## 7. FX — `fx-snapshot.json`

ExchangeRate-API open access endpoint `https://open.er-api.com/v6/latest/USD` ("Rates by
Exchange Rate API", attribution required). `server/live/fx.ts` refreshes live every 12 h and
falls back to this snapshot; the seed uses the snapshot only (deterministic).

## 8. Agricultural reference statistics — `agri-reference.json` (curated)

Order-of-magnitude values with their citations inside the file:

| Country | Mean farm size | Farm-household share | Paddy yield × farm-gate | Agri-loan rate |
|---|---|---|---|---|
| Bangladesh | 0.5 ha (BBS Agriculture Census 2019) | 0.47 | 4.9 t/ha × USD 290/t | 9–12 % |
| Viet Nam (Mekong) | 1.2 ha (GSO census 2016 / IPSARD) | 0.42 | 6.1 t/ha × USD 290/t | 6–9 % |
| Philippines (Central Luzon) | 1.5 ha (PSA CAF 2012, PhilRice) | 0.15 | 4.2 t/ha × USD 340/t | 8–12 % |
| India (Odisha) | 0.95 ha (Agriculture Census 2015-16) | 0.52 | 4.3 t/ha × USD 247/t (MSP) | 7–9 % |
| Indonesia (Java) | 0.4 ha (BPS ST2023) | 0.30 | 5.3 t/ha × USD 360/t (HPP) | 6–12 % |

District farm counts = population / household size × farm-household share × an urban
adjustment for city-dominated districts (Semarang 0.12, Cần Thơ 0.55, Bulacan 0.5, …).
Insurance: weather-index premium 3–8 %, area-yield 4–7 %, indemnity 6–10 % of sum insured;
sum insured = cost of cultivation per ha by country and crop (PMFBY-style scale of finance).
Loans: log-normal sizes around VND 100 M (VN) / PHP 100k (PH). Anticipatory cash: BDT 5,000
per household (WFP/BRAC Bangladesh 2020–2024).

These values calibrate a synthetic demo portfolio; they are not an official statistic.
